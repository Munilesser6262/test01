# クイズサイト (Quiz Website)

日本語のクイズゲームサイトです。

## 機能

- 5つの質問があるクイズゲーム
- 正解・不正解のフィードバック
- スコア表示
- レスポンシブデザイン
- 何度でも再挑戦可能

## 実行方法 / How to Run

### 方法1: 直接ブラウザで開く（最も簡単）
1. `index.html` ファイルをダブルクリック
2. または、`index.html` を右クリック → 「プログラムから開く」→ お好みのブラウザを選択

### 方法2: ローカルサーバーで実行
```bash
# Python 3がインストールされている場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く

# Node.jsがインストールされている場合
npx http-server
# 表示されたURLをブラウザで開く
```

### 方法3: VS Codeの場合
1. VS Codeで `index.html` を開く
2. 「Live Server」拡張機能をインストール
3. `index.html` を右クリック → 「Open with Live Server」

## 使い方

1. 「スタート」ボタンをクリックしてクイズを開始
2. 各質問に答えて「次へ」をクリック
3. 最後に結果とスコアが表示されます
4. 「もう一度」ボタンで再挑戦できます

## ファイル構成

- `index.html` - HTMLメインファイル
- `style.css` - スタイルシート
- `script.js` - クイズロジック
