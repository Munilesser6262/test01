# クイズサイト (Quiz Website)

日本語のクイズゲームサイトです。

## 🎯 機能

- 5つの質問があるクイズゲーム
- 正解・不正解のフィードバック
- スコア表示とパーセンテージ計算
- レスポンシブデザイン（PC・スマホ対応）
- 何度でも再挑戦可能

## 🚀 クイックスタート

### 最も簡単な方法
`index.html` ファイルをダブルクリックするだけ！

### 詳しい実行方法
**→ [SETUP_GUIDE.md](SETUP_GUIDE.md) を参照してください（詳細な手順を記載）**

## 📖 実行方法（概要）

### 方法1: 直接ブラウザで開く（最も簡単）
1. `index.html` ファイルをダブルクリック
2. または、`index.html` を右クリック → 「プログラムから開く」→ お好みのブラウザを選択

### 方法2: ローカルサーバーで実行
```bash
# Python 3がインストールされている場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000/ を開く

# Node.jsがインストールされている場合
npx http-server
# 表示されたURLをブラウザで開く
```

### 方法3: VS Codeの場合
1. VS Codeで `index.html` を開く
2. 「Live Server」拡張機能をインストール
3. `index.html` を右クリック → 「Open with Live Server」

## 🎮 使い方

1. 「スタート」ボタンをクリックしてクイズを開始
2. 各質問に答えて「次へ」をクリック
   - 正解: 緑色 ✅
   - 不正解: 赤色 ❌（正解も緑色で表示）
3. 最後に結果とスコアが表示されます
4. 「もう一度」ボタンで再挑戦できます
