# クイズサイト (Quiz Website)

日本語のクイズゲームサイトです。

## 機能

- 5つの質問があるクイズゲーム
- 正解・不正解のフィードバック
- スコア表示
- レスポンシブデザイン
- 何度でも再挑戦可能

## 使い方

1. `index.html` をブラウザで開きます
2. 「スタート」ボタンをクリックしてクイズを開始
3. 各質問に答えて「次へ」をクリック
4. 最後に結果とスコアが表示されます
5. 「もう一度」ボタンで再挑戦できます

## ファイル構成

- `index.html` - HTMLメインファイル
- `style.css` - スタイルシート
- `script.js` - クイズロジック
